페이지 ① — AX² System과 연구 맥락

본 문서는 ‘단일 알고리즘 논문’이 아니라, AX² System이라는 실험 체계에서 나온 수백 개 실험 중 “창의적 연결” 패턴을 정리한 기술 보고서입니다.
Context / Positioning

AX² System이란 무엇인가

AX²(System: AI Experience & Transformation)은 AI를 단순 도구가 아니라 사고·표현·문제 해결·연구 과정 전반에 참여하는 파트너로 두고, 삶과 일, 연구 활동을 대상으로 다양한 실험을 축적하는 체계입니다.

  • 실험 단위: 글쓰기, 기획, 분석, 생성, 검증, 재구성 등
  • 관찰 대상: 표현력, 통찰 생성, 사고 구조 변화, 재현 가능한 패턴
  • 산출물: 보고서/화이트페이퍼/프로토타입/내부 모듈 설계
핵심 관찰: LLM은 상식적 연결은 강하지만, 사람에게 인상 깊은 ‘원격 연결’은 약하다.

LLM 보완 모듈로서의 위치

이 연구는 LLM을 대체하려는 시도가 아니라, LLM의 구조적 한계를 보완하는 “보조 모델” 중 하나입니다.

페이지 ② — 현재 AI의 한계: 왜 ‘닮은 것’만 잘 연결하는가

트랜스포머/LLM은 기본적으로 유사성(Similarity)에 기반해 연결을 강화합니다. 그래서 “무난하고 상식적”인 문장은 강하지만, “의외의 통찰”은 약해집니다.
Problem / Motivation

현재 방식의 직관

지금의 모델은 대체로 다음 질문에 최적화되어 있습니다.

“A와 B는 얼마나 닮았는가?”

결과적으로 연결 기준이 가까운 개념에 치우치며, 다음과 같은 문장 성향이 나타납니다.

  • 장점: 안정적, 상식적, 오류(겉보기) 적음
  • 단점: 예측 가능, 평범함, 표현의 ‘도약’이 약함
기본 관점(직관적 표현) Connection Strength ∝ Sim(A, B)

사람에게 ‘인상 깊은 연결’은 반대 방향

사람의 통찰/창의성은 보통 멀리 떨어진 개념이 연결될 때 강해집니다. (광고 카피, 문서의 비유, 스토리텔링, 새로운 관점 제시 등)

“A와 B는 닮지 않지만, 둘을 동시에 설명해주는 제3의 개념이 있는가?”

문서

짧은 문장으로 강한 전달(압축)

카피

의외성 + 설득력(기억에 남음)

아이디어

새 관점/새 결합(통찰)

핵심 “유사성 중심”만으로는 통찰 생성이 제한됨

페이지 ③ — 인간의 통찰 구조와 Mediator(C)

인간은 A–B를 직접 연결하기보다, A와 B를 동시에 설명하는 ‘중간 개념(C)’를 찾아 간접적으로 연결합니다. 이 중간 개념을 본 문서에서는 Mediator로 정의합니다.
Concept / Intuition

가장 쉬운 예시

A=디지털과 B=생명은 직접 유사성이 낮습니다. 하지만 C=인공지능은 디지털과도 연결되고 생명과도 연결됩니다.

A와 B는 멀지만, C가 있으면 “설명이 가능해지고 연결이 생긴다”.
  • LLM 관점: “A와 B가 안 닮았으니 관계 없음”
  • 통찰 관점: “둘 다를 설명하는 C가 있나?”

대표 사례(직관용)

A B 중간 개념 C 의미(예)
디지털 생명 인공지능 기술적 통찰
나노 우주 프랙탈 구조적 도약
얼음 불꽃 상태변화 과학적 이해
침묵 웅변 여백 예술적 통찰
Mediator(C) = A와 B를 동시에 설명하는 다리(징검다리) 목표 C를 체계적으로 찾는 계산 규칙 정의

페이지 ④ — 핵심 공식: Wormhole Value Index (WVI)

Mediator(C) 기반 연결이 “비유”가 아니라 “계산 가능한 구조”임을 보이기 위해, 연결 가치를 WVI로 정의합니다.
Formula / Mechanics

공식

WVI(A, B | C) = ( Sim(A, C) × Sim(C, B) ) / ( Sim(A, B) + ε ) - Sim(X,Y): 코사인 유사도(“닮음 점수”) - C: 중간 개념(Mediator) - ε: 0으로 나누는 것을 방지하는 작은 값

해석(중학생 수준 설명)

  • A–C가 가깝고 C–B가 가깝다면: C는 “다리 역할”을 한다.
  • A–B가 멀수록(닮지 않을수록): “의외성/도약” 가능성이 커진다.
  • 따라서 가까운 다리 × 의외성을 동시에 만족할 때 점수가 커진다.

기존 방식과의 대비

기존 어텐션은 기본적으로 닮을수록 강화입니다. 반면 WVI는 “멀리 있는 두 개념을, 강한 중간 개념으로 연결할 때” 가치를 높게 봅니다.

기존 직관

Weight ∝ Sim(A, B)

가까운 것 위주 → 무난/상식적

WVI 직관

Value ∝ (Sim(A,C)×Sim(C,B)) / (Sim(A,B)+ε)

의외성 + 다리(근거) → 통찰/표현력

핵심 메시지: “A–B가 멀다는 사실”이 오히려 가치 있는 연결의 조건이 될 수 있다.
포지션 PoC(개념 증명) 수준의 간단 실험으로도 확인 가능

페이지 ⑤ — Moderator(W): 언제 그 연결이 ‘중요’해지는가

WVI가 “연결의 가능성/가치”를 계산한다면, Moderator(W)는 그 연결이 실제 상황에서 얼마나 강하게 작동해야 하는지(중요도)를 결정합니다.
Context / Gating

문제: 연결이 가능하다고 항상 유효한가?

“멀리 있는 것”을 연결하는 시도는 자칫하면 무작위 연결로 보일 수 있습니다. 그래서 본 모델은 다음을 명확히 분리합니다.

C의 역할

무엇을 연결할 수 있는가?
가능성(다리의 존재)

W의 역할

언제 그 연결이 중요한가?
상황(컨텍스트) 강도

같은 연결이라도 상황이 약하면 의미가 작고, 상황이 강하면 의미가 커질 수 있다.

최종 영향력(Impact) 정의

Impact(A, B) = WVI(A, B | C) × W - W: 상황/맥락의 강도(0~1 등으로 정규화 가능) - 목적: “항상 열리는 연결”이 아니라 “조건부로 열리는 연결”

시뮬레이션 데이터(발표용 예시)

단어 쌍 (A-B) Context(W) W Impact(예)
Cyan – Wrath Extreme Deprivation 0.0 → 1.0 0.0 → 11.33
Encryption – Freedom Totalitarian Surveillance 0.0 → 1.0 0.0 → 6.96
Clock – Terror Crisis Situation 0.0 → 1.0 0.0 → 8.10
메시지 “연결 가능성(C)”과 “연결 중요도(W)”를 분리해 과잉 연결을 제어

페이지 ⑥ — 활용 시나리오: 어디에 써먹을 수 있는가

본 모델은 LLM을 대체하지 않고, LLM이 약한 영역(표현의 도약/통찰)을 보완하는 창의적 연결 모듈로 설계됩니다.
Applications / Value

광고 카피/표현력 강화

평범한 문장을 “기억에 남는 문장”으로 바꾸는 데 핵심은 의외하지만 설득 가능한 연결입니다.

  • LLM 결과에서 원격 연결 후보를 탐색
  • 중간 개념(C) 기반으로 “근거 있는 비유/메타포” 제안
  • 상황(W)으로 톤/맥락 적합성 조절

문서/보고서/스토리텔링

설명이 길어질수록 전달력은 떨어지고, 짧은 문장으로 압축되는 순간 설득력이 생깁니다.

  • 핵심 메시지에 대해 “다리(C)”를 찾아 압축 문장 생성
  • 추상/구체를 연결하는 비유 구조 강화
  • 독자가 “아!” 하고 이해하는 문장 패턴 유도

창의적 생성 엔진의 보조 모듈

LLM이 만든 초안을 그대로 쓰지 않고, 후처리(재연결) 단계에서 통찰을 강화합니다.

  • 1차 생성 → 2차 “WVI 스캐닝”으로 원격 연결 후보 생성
  • Moderator(W)로 상황 적합한 연결만 채택
  • 선택된 연결을 문장/구조/아이디어로 재구성

권장 사용 방식(시스템 관점)

파이프라인 예시

Step 1) LLM이 기본 초안 생성 Step 2) (A,B) 후보를 설정(키워드/문장/의도) Step 3) C 후보를 탐색 → WVI 최대화 Step 4) Context W를 반영 → Impact로 게이팅 Step 5) 선택된 연결을 “표현/비유/관점”으로 재작성

설득 포인트

  • 간단한 공식으로도 “관점 전환”을 만든다
  • 핵심 구현은 내부 자산으로 보호 가능(공개 범위 조절)
  • 보고서/발표에서는 PoC와 사례로 “감이 아님”을 증명
한 문장 요약: 멀리 떨어진 개념을, 중간 개념과 상황을 통해 ‘조건부로’ 연결해 표현력과 통찰을 확장한다.
핵심 가치 표현력↑, 통찰↑, “평범함” 감소 형태 LLM + 보조 모듈(후처리/재연결)
