제4장. GPT: 생성형 사전학습(Generative Pre-training)

: 다음 단어를 맞추다 보니, 세상의 패턴을 깨우치다

제4장은 GPT(Generative Pre-trained Transformer)가 어떻게 인공지능의 패러다임을 '지도 학습(Supervised)'에서 '자기지도 학습(Self-Supervised)'으로 전환시켰는지, 그리고 그 단순한 학습 방식이 어떻게 인간 수준의 언어 능력을 만들어냈는지를 규명합니다.

4.1. Decoder-Only 아키텍처의 선택 이유

4.1.1. 이해(Encoder) vs 생성(Decoder)

BERT가 문장의 빈칸을 채우는 이해(Understanding)에 집중했다면, OpenAI는 "지능의 본질은 다음 상황을 예측하는 능력이다"라고 판단하여 디코더(Decoder) 구조를 선택했습니다.

4.1.2. 인과적 마스킹 (Causal Masking)

일반적인 Attention과 달리, 미래의 단어를 미리 보지 못하도록 가리는(Masking) 기법입니다. 이는 시간의 흐름에 따라 사고하는 자기회귀(Autoregressive) 특성을 부여합니다.

핵심: 불확실한 미래를 예측하기 위해, 모델은 단순한 패턴 매칭을 넘어 세상이 돌아가는 원리(World Model)를 내부적으로 구축해야만 했습니다.

4.2. 자기지도 학습: 데이터 라벨링의 종말

4.2.1. 데이터가 곧 정답이다

기존 지도 학습은 사람이 일일이 정답(Label)을 달아야 했지만, 자기지도 학습은 인터넷 텍스트 그 자체를 정답지로 활용합니다.

  • 입력: "대한민국의 수도는"
  • 목표: "서울" (다음 단어)

이 방식 덕분에 라벨링 비용이 '0'이 되었고, 위키피디아와 책 등 인터넷의 모든 데이터를 학습 재료로 쓸 수 있게 되었습니다.

4.2.2. 다음 토큰 예측 (Next Token Prediction)

단순해 보이지만, 다음 단어를 정확히 맞추기 위해서는 문법, 상식, 논리적 추론 능력이 모두 필요합니다.

4.3. Scaling Laws: 거대함이 곧 지능이다

4.3.1. 카플란의 발견 (Power Law)

OpenAI 연구진은 모델의 성능(Loss)이 모델 크기(\(N\)), 데이터 양(\(D\)), 연산량(\(C\))과 로그 함수 관계를 그리며 정직하게 비례한다는 사실을 발견했습니다.

\[ L(N) \approx (N_c/N)^\alpha \]

4.3.2. 창발성 (Emergence)

모델이 특정 임계점을 넘어서는 순간, 이전에는 없던 능력(코딩, 산술 연산 등)이 갑자기 튀어나오는 현상입니다. 이는 양(Quantity)이 질(Quality)을 변화시킨다는 것을 의미합니다.

4.3.3. GPT 시리즈의 진화

모델 출시 연도 파라미터 수 특징
GPT-1 2018 1.17억 개 가능성 확인
GPT-2 2019 15억 개 문맥 이해 및 작문 시작
GPT-3 2020 1,750억 개 Few-shot Learning 발현, 상업적 가치 증명

4.4. In-Context Learning: 가르치지 않아도 배운다

GPT-3부터는 별도의 파라미터 업데이트(Fine-tuning) 없이, 프롬프트 창에 예시를 보여주는 것만으로 작업을 수행하는 능력이 생겼습니다.

4.4.1. Zero, One, Few-shot

[Few-shot 예시]
영어: Good morning -> 한국어: 좋은 아침
영어: Apple -> 한국어: 사과
영어: Thank you -> 한국어:

모델은 위 예시를 보고 "아, 번역을 하라는 거구나"라고 패턴을 파악하여 "고맙습니다"라는 정답을 내놓습니다. 이를 메타 학습(Meta-Learning)이라고도 합니다.

4.5. 결론: 똑똑하지만 제멋대로인 천재

GPT는 인터넷의 모든 지식을 흡수했지만, 치명적인 문제가 남았습니다.

  • 목표 불일치: 사용자의 의도(Intent)보다는 확률적으로 이어질 말을 생성하는 데 집중합니다.
  • 환각(Hallucination): 그럴듯한 거짓말을 천연덕스럽게 지어냅니다.
  • 편향(Bias): 학습 데이터에 포함된 혐오 표현이나 차별을 그대로 답습합니다.
요약: "우리는 페라리 같은 강력한 엔진(GPT)을 만들었다. 하지만 이 차에는 핸들과 브레이크(Alignment)가 없다."
이 문제를 해결하기 위해 제5장. ChatGPT(RLHF)가 등장합니다.
