제6장. Post-ChatGPT: Agents & Reasoning

: "말만 잘하는 AI"에서 "생각하고 행동하는 AI"로

제6장은 ChatGPT 이후, AI 기술이 단순한 '언어 모델(LLM)'을 넘어 '이성적 추론(Reasoning)'과 '자율적 행동(Action)' 능력을 갖춘 에이전트(Agent)로 진화하는 과정을 다룹니다.

6.1. 단순 응답기에서 문제 해결기(Solver)로의 전환

6.1.1. 확률적 앵무새의 딜레마

초기 LLM은 '그럴듯한 문장(Plausibility)'을 만드는 데 최적화되어 있었습니다. 문학적 창작에는 유리했지만, 수학이나 논리 문제에서는 "23,984 곱하기 1,232"를 실제로 계산하지 않고 확률적으로 찍어서 맞추려는 경향이 있었습니다.

6.1.2. Solver의 정의

이제 AI의 목표는 진실(Truth)과 엄밀성(Rigor)입니다. 단순한 챗봇이 아니라, 복잡한 문제를 단계별로 논파하고 검증 가능한 정답을 내놓는 Solver가 되어야 합니다.

6.2. Chain of Thought (CoT): 단계적 추론 능력의 강화

6.2.1. 발견: "성급한 결론"의 문제

AI가 틀리는 가장 큰 이유는 중간 계산 없이 질문에서 정답으로 바로 건너뛰려 하기 때문입니다(비약). 이를 해결하기 위해 중간 추론 단계를 생성하게 했습니다.

6.2.2. Zero-shot CoT: 마법의 주문

모델을 재학습시키지 않고도, 프롬프트 끝에 단 한 문장을 추가하는 것만으로 추론 능력이 비약적으로 상승했습니다.

"Let's think step by step." (단계별로 생각해 보자.)

이 기법은 AI에게 '생각할 시간(Time to Think)'과 '메모할 공간'을 주는 것과 같습니다. 더 많은 연산(Token)을 사용하여 문제를 잘게 쪼개고 순서대로 풀게 만듭니다.

6.3. AI Agents: 도구 사용(Tool Use)과 외부 환경 상호작용

6.3.1. 뇌에 손발을 달다

AI가 텍스트 감옥을 탈출하여 현실 세계의 도구를 조작합니다. 자신의 지식만 고집하지 않고, 부족한 정보는 검색하고 복잡한 계산은 코드를 실행해서 해결합니다.

6.3.2. 작동 원리: ReAct (Reasoning + Acting)

에이전트는 [계획 → 행동 → 관찰 → 수정]의 루프를 돕니다.

ReAct 예시: "아이유 나이에 2를 곱하면?"

  1. Thought: 아이유 생년월일을 먼저 검색해야 해.
  2. Action: Search("아이유 나이")
  3. Observation: "1993년생이다."
  4. Thought: 이제 2024년 기준으로 계산하고 2를 곱하자. 계산기를 쓰자.
  5. Action: Calculator((2024-1993)*2)
  6. Answer: "62세입니다."

6.4. System 2 Thinking: o1 모델과 Test-time Compute

6.4.1. System 1 vs System 2

대니얼 카너먼의 이론을 적용했습니다.

  • System 1 (기존 LLM): 직관적이고 빠른 반응. 실수가 잦음.
  • System 2 (o1 모델): 느리고 신중한 숙고. 논리적이고 정확함.

6.4.2. Test-time Compute (추론 시간 연산)

새로운 패러다임은 "답변을 생성하기 전, 추론하는 시간을 늘리는 것"입니다. OpenAI의 o1 모델은 사용자가 질문하면 수초에서 수십 초간 Thinking... 상태를 유지하며, 내부적으로 가설을 검증하고 오류를 스스로 수정(Self-Correction)한 뒤 최적의 답을 내놓습니다.

결론: AI는 이제 "답이 나올 때까지 밤새워 고민하는 박사급 연구자"의 능력을 갖추기 시작했습니다.
