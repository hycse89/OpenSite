Chapter 4 ~ 8: 단계, 평가, 비용, 운영

4. PSSLAB 접근의 목적과 원칙

  • 4.1 교육이 아닌 환경 설계: 가르침보다 조건, 관리보다 구조.
  • 4.2 빠르되, 소모하지 않음: 조기 투입하되 사람을 갈아 넣지 않는 설계.
  • 4.3 지속적 성장: AX는 한 번의 학습으로 끝나지 않음.

5. 단계별 구조 설계

성취(Achievement)가 아니라 역할과 책임(Responsibility)의 단계

Level Structure Overview

수료 관찰자: 세계관 공유, 부적합 조기 인식

브론즈 실무자: "사람 구실", CS 기초, 기본 설계

실버 전문가: 자기주도 문제 정의, 실패 분석

골드 기여자: 공동 실험, 방법론 개선

블랙 창작자: 구조 설계, 철학 공유

5.3 브론즈 (Bronze): 생존선

"어디에 가도 기본적인 역할을 수행할 수 있는 AX 실무자"
  • AI만 아는 사람은 브론즈가 될 수 없음.
  • 요구사항: CS 기초(3학년 수준), 논리적 사고, AI(Chat/API) 구분 사용.
  • 수학/영어는 강요하지 않으나, 사용 안 하면 자연스럽게 정체됨.

5.4 실버 (Silver): 설계자

  • 성격: 석사 과정과 유사한 자기주도성 요구.
  • 핵심: 정답이 없는 문제를 정의하고, 결과를 재현 가능하게 설명.
  • 영어: 글로벌 AX 환경 적응을 위한 영어 발표/자료 활용 도입.

5.5 골드/블랙: 공동 창작자

시험 통과가 아니라 기여(Contribution) 기반 승급.

  • 컨텐츠 확장에 기여.
  • 타인의 성장 촉진.
  • 시스템의 공동 책임자.

6. 평가·탈락·재진입

선별이 아닌 책임 기반 흐름 설계

6.1 평가의 본질

점수 매기기가 아니라 "누가 어떤 책임을 질 수 있는가"를 확인.

  • 자동 탈락: 미제출, 기준 미달 시 예외 없음. 정치적 판단 배제.
  • 평가 기준: 문제 정의, 설계 정당성, 설명 가능성, 재현 가능성.

6.4 비용과 로그를 평가 도구로

"비용은 돈 문제가 아니라 설계 능력의 문제다."

  • 무분별한 토큰 사용 = 설계 능력 부족.
  • 비용 대비 가치, 모델 선택의 정당성을 평가.

6.6 재진입

탈락은 영원한 실패가 아닙니다.

  • 일정 기간 후 재진입 허용.
  • 재진입은 '구제'가 아니라 '책임의 재선택'.

7. AI 사용 구조와 비용

비용 폭탄은 '비싸서'가 아니라 '통제되지 않아서' 발생합니다.

7.3 중앙 게이트웨이 (Central Gateway)

  • 개인 결제/API 키 사용 지양 (공정성 확보).
  • 중앙에서 사용량, 모델, 로그 관리.
  • 로그를 역량 평가의 핵심 근거로 활용.

7.4 Chat/API & LLM/SLM 동시 제공

초기부터 4가지 환경을 모두 제공합니다.

  1. Chat LLM
  2. Chat SLM
  3. API based LLM
  4. API based SLM

SLM과 API를 모르면 AX 설계를 할 수 없습니다.

8. AI 기반 운영 시스템

운영은 목적이 아니라 조건입니다.

8.1 운영의 병목 제거

  • 운영자 개인의 체력에 의존하지 않는 구조.
  • 판단은 규칙으로, 실행은 시스템(AI)으로.

8.3 AI의 운영 역할

  • 과제 생성: 개인별 난이도 조정.
  • 1차 평가: 형식 요건, 설명 구조 분석.
  • 로그 분석: 사고와 설계의 흔적 추적.

인간 운영자는 관리자가 아니라 구조 설계자로 남습니다.
