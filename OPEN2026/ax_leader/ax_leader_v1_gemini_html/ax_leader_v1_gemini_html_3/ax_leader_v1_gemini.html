0. Executive Summary

문제의식
  • 구조적 불일치: 산업(월 단위) vs 교육(년 단위) 속도 차이.
  • 기존 한계: 대학은 검증 중심이라 대응 느림.
  • 위험: 상업 교육의 성과 압박이 학생에게 전가됨.
핵심 정의

PSS → ADS → DX → AX

  • AX는 유행어가 아닌 인간-시스템 관계의 장기 연구.
  • 특정 도구 종속 없이 철학과 구조 유지.
해결책: 환경 설계
1. 실전 환경: Chat/API, LLM/SLM 전제
2. 규칙 기반: 예외 없는 기준과 재현성
3. 자동 선별: 선택에 따른 결과(탈락/승격)
4. 지속 성장: 장기 지식 인프라 제공
"빠르되, 소모하지 않는다. 교육이 아니라 환경을 제공한다."

1. 문제 정의: 구조적 불일치

1.1 수요 폭발

AX 인력 ≠ 단순 기술자

  • AI를 업무 파트너로 인식
  • 문제를 AI 친화적으로 재정의
  • 비용/리스크 고려 설계
1.2 속도 괴리
  • 산업: 월 단위 변화
  • 교육: 학위/학기 단위

*교육이 느린 건 설계 목적이 다르기 때문.

1.3 대학 한계
  • 형식(학점/논문) 중심 평가
  • 최신 도구 환경 제공 난항
  • 역할 분리의 경직성
제3의 경로 필요성
구분 대학 모델 상업 교육 PSSLAB 모델
속도 느림 (검증) 빠름 (결과) 빠름 (실험)
리스크 낮음 학생 전가 구조 흡수

2.6 AX의 필연성

"AX는 DX로 확장된 Digital 시스템을 다시 인간 경험(Analog)으로 재통합하는 국면."

  • AI는 도구가 아닌 인간 판단을 증폭시키는 행위자.

3. PSS → ADS → DX → AX 계보

3.1 계보의 중요성
  • AX를 "DX 다음 단계"나 "단순 유행"으로 보면 실패.
  • 구조적 변화의 최신 국면으로 이해해야 함.
3.7 역할 재설계

"무엇을 자동화할 것인가" (X)
"무엇을 인간이 계속할 것인가" (O)

  • 기술 선택보다 역할 설계가 핵심.
3.8 인력 형성: AX 인력은 새로운 기술자가 아니라, 인간-AI 관계를 설계할 수 있는 사람이다.

5. 단계별 구조 (Levels)

단계 = 성취(Achievement)가 아닌 책임(Responsibility)의 범위

⚪ 수료 (Completion)
"아는 사람" / 관찰자
  • 목표: 세계관 이해, 부적합 조기 인식.
🟤 브론즈 (Bronze)
"쓸 수 있는 사람" (생존선)
  • 필수: AI(Chat/API) + CS 기초(3학년).
⚪ 실버 (Silver)
"설계하는 사람" (석사급)
  • 목표: 자기주도 문제 정의, 영어 발표.
🟡 골드/블랙
"만드는 사람" (공동 창작)
  • 기준: 시험(X) → 기여(O) 기반 승급.

6. 평가·탈락·재진입

평가 본질 & 자동 탈락
  • "누가 책임을 질 수 있는가" 확인.
  • 자동 탈락: 미제출, 기준 미달 시 예외 없음.
  • 탈락은 실패가 아니라 '구조적 부적합' 확인.
핵심 평가 기준
  1. 문제 정의: AX 의미가 있는가?
  2. 설계 정당성: 모델 선택 이유?
  3. 설명/재현 가능성: 이해 및 로그 확인.
6.4 비용 = 설계 능력 지표
  • 무분별한 토큰 사용 = 감점 (설계 부족).
  • 비용 절감을 위한 구조적 시도 = 가점.

7. AI 사용 구조와 비용

"비용은 돈 문제가 아니라 구조 통제의 문제다."
7.3 중앙 게이트웨이
  • 방식: 개인 결제 금지. 중앙 관리형 계정.
  • 장점: 공정성 확보, 비용 예측 가능.
  • 기능: 로그 전수 수집 → 평가 활용.
7.4 4대 환경 제공

초기부터 아래 4가지를 모두 제공

  • Chat LLM
  • Chat SLM
  • API LLM
  • API SLM

8.3 AI의 역할
  • 과제: 자동 생성/난이도 조정.
  • 평가: 형식 요건, 설명 구조, 로그 분석.
  • 로그: 사고의 흔적 분석.
8.5 감정 노동 제거
  • 탈락/피드백을 규칙 기반 시스템이 수행.
  • 개인적 거절이 아닌 '구조적 결과'로 인식.

9. 비독점적 전수와 재현

확대(Scale) vs 재현(Repro)
  • 확대 지양: 독점, 종속성, 리스크 증가.
  • 재현 지향: 각자 맥락에서 자율 작동.
  • 목표: 창시자 없이 돌아가는 시스템.
파일럿의 의미
  • 사람 시험(X) → 구조 검증(O).
  • 실패 사례까지 지식으로 정리.
지속적 기여: 중앙이 운영 권한을 독점하지 않으며, 기여는 지속되나 통제는 없다.

10. 컨텐츠 전략

"컨텐츠는 정답집이 아니라, 사고와 실험의 축적(성장 인프라)이다."
10.3 구성 요소
  1. 방법론: 문제 정의 프레임.
  2. 실패 기록: '왜 안 되었는가' 중시.
  3. 기술 MVP: 사고의 출발점 제공.
10.5 컨텐츠와 사람
  • 컨텐츠는 락인(Lock-in) 수단 아님.
  • 떠나서도 성장하게 하는 도구.
  • 사고 프레임은 개인에게 남는다.

12. 지향하지 않는 것

윤리적 안전장치를 위한 부정(Not)의 선언

학생 수단화 금지
  • 마케팅용 성공 사례 소비 금지.
  • 학생은 증거가 아닌 경험 주체.
영속화 목표 아님
  • 창시자/조직 중심 거부.
  • 사람 사라져도 구조는 남아야 함.
정답/안전 미제공
  • 불확실성을 다루는 법 훈련.
  • 취업 보장 등 약속 안 함.
정치적 구조 배제
  • 추천/특혜 없음.
  • 예외 없는 규칙으로 신뢰 유지.
